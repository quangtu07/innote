# Innote 0.8.9 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Phát hành 0.8.9 với thông báo cập nhật, thư viện cuộc họp riêng và sửa thu gọn cài đặt phụ đề.

**Architecture:** Dùng dialog theo phiên bản và pipeline NSIS/updater đang có. Ký bằng khóa hiện tại; tải artifact lên draft trước rồi công bố sau khi kiểm tra. Thực hiện trực tiếp theo yêu cầu build/release của người dùng.

**Tech Stack:** Svelte 5, Rust/Tauri v2, NSIS, GitHub CLI.

**Spec:** Yêu cầu người dùng ngày 08/11/2026: tạo box thông báo phiên bản mới, build, release và đẩy GitHub; giữ dữ liệu cũ và chỉ hiện thông báo một lần sau cập nhật.

## Global Constraints

- Version 0.8.9 đồng bộ package/lock, Cargo/lock và tauri.conf.
- Không đưa API key, dữ liệu cuộc họp hoặc tệp untracked không liên quan lên GitHub.
- Không đóng phiên ghi hoặc phụ đề đang chạy. Dùng fixture cho QA.
- Không thay public key updater. Commit author tu-dev; không giả tài khoản GitHub.
